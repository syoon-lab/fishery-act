# fishery-act — 수산업법 포획 규제 정리

「수산업법」·「수산업법 시행령」의 포획 관련 규제를 정리하는 프로젝트.
어종 중심 서비스인 [fishery-regulation](https://fishery-regulation.vercel.app)(수산자원관리법 체계:
금어기·금지체장·금지 대상)과 축이 달라 별도로 분리했다 (2026-08-01 결정).

## 정리 대상

| 주제 | 근거 | 상태 |
|---|---|---|
| 어업 정의의 목적어종 한정 (기선권현망=멸치 등) | 시행령 제21조~제23조 | 초안 확보 (`docs/`, `references/text/`) |
| 혼획이 허용되는 어업·수산동물·허용 범위 | 법 제42조, 시행령 제24조·별표 3 | 미착수 |
| 어업의 종류별 어구사용 금지구역·금지기간 | 시행령 제38조제2항·별표 7 (20쪽) | 미착수 |
| 근해어업의 조업구역·허가정수 | 시행령 제31조·별표 5 | 미착수 |
| 어구의 규모·그물코 규격 제한 | 시행령 제38조·별표 2·8·9 | 미착수 |

## 구조

```
references/text/   # 법령 원문 추출 텍스트 (추출일 표기)
docs/              # 정리 문서·페이지 초안
```

- `docs/draft-page-FisheriesActPage.tsx`: fishery-regulation에 잠시 만들었다 분리한
  목적어종 한정 안내 페이지 초안 (React, 표 데이터 포함) — 재사용 가능.
